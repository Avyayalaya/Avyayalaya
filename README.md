### Flagship Projects

**[agent-prime](https://github.com/avyayalaya/agent-prime)** — 13-agent operating system that turns one person into a team. Persistent memory, recursive self-improvement, 42+ encoded decisions. Markdown and JSON. Zero dependencies.

**[india-energy](https://github.com/avyayalaya/india-energy)** — India's energy supply chain as a live nervous system. 39 trade routes, 23 refineries, 123 power plants. Hormuz crisis simulation in a single HTML file.

**[stratum](https://github.com/avyayalaya/stratum)** — Meta-skill framework for evaluating human capability. 15 meta-skills across 3 domains. Agentic CLI assessment. Built from chaos theory, quantum mechanics, and 15 years of hiring.

**[pm-skills-arsenal](https://github.com/Avyayalaya/pm-skills-arsenal)** — 12 product management skills, each 1,100–1,300 lines of methodology, frameworks, and failure modes. APM-installable, bundles an MCP server, listed in [`github/awesome-copilot`](https://github.com/github/awesome-copilot). The `98/105` benchmark cited in the repo is self-administered (same author wrote the rubric and scored every output); raw outputs are at [`benchmark/`](https://github.com/Avyayalaya/pm-skills-arsenal/tree/main/benchmark) for independent re-scoring.

**[agent-council](https://github.com/Avyayalaya/agent-council)** — 5-agent quality gate for tier-1 text artifacts. Five role-conditioned LLM deliberators (Skeptic, Voice & Identity, Evidence & Calibration, Strategy & Stakes, Adjudicator) run a 2-round async + cross-read protocol; one verdict (SHIP / REVISE / HOLD), one revision brief, full audit transcript. APM-installable, bundles an MCP server, 4 runtime adapters (claude_cli, lmstudio, ollama, mock_cli). v0.1.0 ships architecture + design only; empirical evaluation (3-arm benchmark with confidence intervals + arXiv paper) lands in v0.2. First quality-gate domain in the [`awesome-apm`](https://github.com/Avyayalaya/awesome-apm) index.
